WebGIS berbasis Leaflet + Turf + Plotly

Analisis gridding, interpolasi, output JPG, dan visualisasi 3D dari ROI.

Buat ROI langsung di basemap online, pilih sumber DEM, tentukan metode gridding dan interpolasi, lalu klik Tampilkan Analisis. Hasil akan muncul otomatis di bawah peta dalam bentuk gambar JPG, ringkasan statistik, overlay interpolasi, dan surface 3D.

Catatan penggunaan

File ini dibuat sebagai index.html tunggal sehingga bisa langsung masuk GitHub Pages. Untuk data DEM asli resolusi tinggi, bagian pengambilan DEM perlu disambungkan ke API atau backend. Versi ini sudah menjalankan simulasi DEM, gridding, interpolasi, JPG, dan 3D sepenuhnya di browser.
